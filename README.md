# เรียน LLM จากศูนย์ จนสร้างเองได้

หลักสูตรภาษาไทยสำหรับคนที่เขียนโปรแกรมเป็น แต่ไม่ถนัดคณิตศาสตร์
เป้าหมายคือเข้าใจว่า LLM ทำงานอย่างไร **รวมถึงคณิตศาสตร์เบื้องหลังและที่มาของมัน**
แล้วเขียน GPT ขนาดเล็กขึ้นมาเทรนเองได้

## เหมาะกับใคร

- เขียนโปรแกรมภาษาใดภาษาหนึ่งได้คล่อง (ตัวอย่างเปรียบเทียบในบทเรียนใช้ Java)
- อ่านและเขียน Python ได้ระดับพื้นฐานถึงกลาง
- **ไม่จำเป็นต้องมีพื้นคณิตศาสตร์** บทเรียนเริ่มจากระดับ ม.ต้น และอธิบายทุกสูตรที่ใช้

## แนวทางการสอน

1. **เริ่มจากปัญหา แล้วค่อยมีสูตร** ทุกสูตรจะบอกก่อนว่ามันถูกคิดขึ้นมาแก้ปัญหาอะไร ใครคิด และเมื่อไร
2. **พิสูจน์ด้วยมือ แล้วตรวจด้วยโค้ด** ทุกผลลัพธ์ทางคณิตศาสตร์จะมีโค้ด Python ให้รันยืนยัน
3. **ไม่ข้ามขั้น** ถ้าบทไหนใช้ความรู้ใหม่ จะมีบทปูพื้นก่อนเสมอ
4. **ลงมือทำ** ทุกบทมีแบบฝึกหัดและเฉลยแยกไฟล์
