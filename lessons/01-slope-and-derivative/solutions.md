## ข้อ 1

$h = 1$: $\frac{f(6) - f(5)}{1} = \frac{36 - 25}{1} = 11$

$h = 0.1$: $\frac{f(5.1) - f(5)}{0.1} = \frac{26.01 - 25}{0.1} = 10.1$

ค่าเข้าใกล้ 10 ตรงกับ $f'(5) = 2 \times 5 = 10$ และแต่ละค่าเท่ากับ $2x + h$ พอดี ($10 + 1$ และ $10 + 0.1$)

## ข้อ 2

$$\frac{5(x+h)^2 - 5x^2}{h} = \frac{5x^2 + 10xh + 5h^2 - 5x^2}{h} = \frac{10xh + 5h^2}{h} = 10x + 5h$$

เมื่อ $h$ เข้าใกล้ศูนย์ พจน์ $5h$ หายไป เหลือ $f'(x) = 10x$

ตรวจกับกฎคูณค่าคงที่: $5 \times (\text{อนุพันธ์ของ } x^2) = 5 \times 2x = 10x$ ตรงกัน

## ข้อ 3

- $x^3$ ได้ $3x^2$
- $2x$ ได้ $2$

$f'(x) = 3x^2 + 2$ ดังนั้น $f'(1) = 3 + 2 = 5$

`slope(lambda x: x**3 + 2*x, 1, 1e-6)` ให้ค่า `5.000002999633324`

## ข้อ 4

$$\frac{(x+h)^3 - x^3}{h} = \frac{x^3 + 3x^2h + 3xh^2 + h^3 - x^3}{h} = \frac{3x^2h + 3xh^2 + h^3}{h} = 3x^2 + 3xh + h^2$$

- $x^3$ ตัดกับ $-x^3$
- $3x^2h$ มี $h$ ตัวเดียว หารแล้วเหลือ $3x^2$ เป็นคำตอบ
- $3xh^2$ และ $h^3$ มี $h$ มากกว่าหนึ่งตัว หารแล้วยังเหลือ $h$ จึงหายไปเมื่อ $h$ เข้าใกล้ศูนย์

$f'(x) = 3x^2$ ตรงกับกฎยกกำลัง $n \cdot x^{n-1}$ เมื่อ $n = 3$

## ข้อ 5

```python
from slope import gradient_descent

df = lambda x: 2 * (x - 3)
for lr in [0.01, 0.5, 1.0, 1.1]:
    print(lr, [round(v, 4) for v in gradient_descent(df, 0.0, lr, 6)])
```

```

0.5  [0.0, 3.0, 3.0, 3.0, 3.0, 3.0, 3.0]
1.0  [0.0, 6.0, 0.0, 6.0, 0.0, 6.0, 0.0]
1.1  [0.0, 6.6, -1.32, 8.184, -3.2208, 10.465, -5.958]
```

1. ผลของแต่ละค่า

| learning rate | พฤติกรรม |
|---|---|
| 0.01 | ไปถูกทางแต่ช้ามาก 6 ก้าวได้แค่ 0.34 (หลัง 100 ก้าวยังอยู่ที่ 2.60) |
| 0.5 | ถึง 3 ในก้าวเดียว |
| 1.0 | กระโดดไปมาระหว่าง 0 กับ 6 ไม่เข้าใกล้คำตอบเลย |
| 1.1 | กระโดดข้ามไปมาและไกลออกไปเรื่อย ๆ |

2. ที่ `lr = 1.0`
   - ก้าวแรก: ความชันที่ $x = 0$ คือ $2(0-3) = -6$ ได้ $x = 0 - 1.0 \times (-6) = 6$
   - ก้าวที่สอง: ความชันที่ $x = 6$ คือ $2(6-3) = 6$ ได้ $x = 6 - 1.0 \times 6 = 0$

   ก้าวยาวเท่ากับสองเท่าของระยะถึงก้นชามพอดี จึงข้ามไปอยู่ฝั่งตรงข้ามที่ความสูงเท่าเดิม แล้ววนกลับมา

3. เล็กเกินไปยังได้คำตอบที่ถูก แต่ใช้เวลานาน ใหญ่เกินไปจะข้ามก้นชาม ถ้าใหญ่มากค่าจะระเบิดออกไป
   ซึ่งตอนเทรนโมเดลจริงจะเห็นเป็น loss ที่พุ่งขึ้นหรือกลายเป็น `nan`

**มองให้ลึกขึ้น:** แทน $f'(x) = 2(x-3)$ ลงในสูตร แล้วดูระยะห่างจากคำตอบ

$$x_{\text{ใหม่}} - 3 = (x - 3) - \eta \cdot 2(x - 3) = (1 - 2\eta)(x - 3)$$

แต่ละก้าวคูณระยะห่างด้วย $(1 - 2\eta)$

| $\eta$ | $1 - 2\eta$ | ความหมาย |
|---|---|---|
| 0.01 | 0.98 | ระยะห่างลดก้าวละ 2% |
| 0.5 | 0 | ระยะห่างเป็นศูนย์ทันที |
| 1.0 | −1 | ระยะห่างเท่าเดิม แต่สลับฝั่ง |
| 1.1 | −1.2 | ระยะห่างโตขึ้นก้าวละ 20% และสลับฝั่ง |

การที่ `0.5` ถึงในก้าวเดียวเป็นความบังเอิญของฟังก์ชันนี้ ฟังก์ชันอื่นจะมีค่าที่เหมาะสมต่างกัน
และกับโมเดลจริงเราไม่มีทางรู้ค่านี้ล่วงหน้า จึงต้องทดลอง

## ข้อ 6

1. $f'(x) = 4x^3 - 6x + 1$

2. และ 3.

```python
from slope import gradient_descent

f = lambda x: x**4 - 3 * x**2 + x
df = lambda x: 4 * x**3 - 6 * x + 1
for start in [2.0, -2.0, 0.0]:
    x = gradient_descent(df, start, 0.01, 2000)[-1]
    print(start, round(x, 4), round(f(x), 4))
```

| จุดเริ่มต้น | จบที่ $x$ | $f(x)$ |
|---|---|---|
| 2.0 | 1.1309 | −1.0702 |
| −2.0 | −1.3008 | −3.5139 |
| 0.0 | −1.3008 | −3.5139 |

4. ไม่รับประกัน กราฟนี้มีก้นสองแห่ง เมื่อเริ่มจาก 2.0 จะไปติดที่ก้นตื้น ($-1.0702$) ทั้งที่มีก้นที่ลึกกว่า ($-3.5139$)
   gradient descent เห็นแค่ความชันตรงที่ยืนอยู่ พอถึงจุดที่ความชันเป็นศูนย์ก็หยุด

   ก้นที่ไม่ใช่จุดต่ำสุดของทั้งกราฟเรียกว่า **local minimum** ส่วนจุดต่ำสุดจริงเรียกว่า **global minimum**
   ผลลัพธ์จึงขึ้นกับจุดเริ่มต้น นี่เป็นเหตุผลที่การสุ่มค่า weight เริ่มต้นมีผลต่อโมเดลที่ได้

## ข้อ 7

1. $\text{loss}(w) = (3w - 12)^2$

2. กระจาย: $(3w - 12)^2 = 9w^2 - 72w + 144$ ดังนั้น $\frac{d\,\text{loss}}{dw} = 18w - 72$

3. $18w - 72 = 0$ ได้ $w = 4$ (ตรวจ: $4 \times 3 = 12$)

4. โค้ด

```python
from slope import gradient_descent

dloss = lambda w: 18 * w - 72
path = gradient_descent(dloss, 0.0, 0.02, 30)
print(path[-1])
```

ได้ `3.9999938...` ซึ่งเข้าใกล้ 4

learning rate ที่ใช้ได้ต้องน้อยกว่าประมาณ 0.11 ใช้วิธีเดียวกับข้อ 5 จะได้ว่าแต่ละก้าวคูณระยะห่างด้วย $(1 - 18\eta)$
ซึ่งต้องมีขนาดน้อยกว่า 1 จึงจะเข้าใกล้คำตอบ นั่นคือ $\eta < \frac{2}{18} \approx 0.111$

สังเกตว่าขอบเขตนี้เล็กกว่าข้อ 5 (ซึ่งคือ $\eta < 1$) เพราะชามของข้อนี้ชันกว่า **ยิ่งชัน ยิ่งต้องก้าวสั้น**
